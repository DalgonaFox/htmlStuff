Este repositório funciona como um guia prático e comentado sobre **HTML5**. Ele foi criado para documentar, explicar e exemplificar o uso de diversas tags (desde as mais comuns até as mais raras) e a aplicação de boas práticas de estruturação semântica na web.

É um excelente material de consulta rápida para relembrar como estruturar páginas e utilizar recursos nativos do navegador sem precisar depender excessivamente de CSS ou bibliotecas externas.

## 📂 O que você vai encontrar aqui?

O repositório contém arquivos de estudo focados em diferentes aspectos da linguagem:

### 1. Dicionário de Tags Úteis e Boas Práticas
Um documento repleto de exemplos práticos de tags de texto, formulários e elementos interativos. Alguns dos tópicos abordados incluem:
* **Configurações de Head:** Uso de tags `<meta>` para SEO e propriedades *Open Graph* para criação de previews ricos no Discord e WhatsApp.
* **Formulários Dinâmicos:** Demonstração de inputs avançados como `<datalist>` (recomendações automáticas), `color`, `range` e seletores nativos de data/hora (`datetime-local`).
* **Interatividade Nativa:** Criação de dropdowns com `<details>` e `<summary>`, e janelas de pop-up/modais utilizando a tag `<dialog>` controlada por Javascript simples.
* **Acessibilidade e Tags Específicas:** Uso de `<ruby>` para anotações fonéticas, `<meter>` e `<progress>` para barras de status, `<picture>` para design responsivo e `<template>` para criação de blocos repetíveis na DOM.

### 2. Estrutura de HTML Semântico
Um guia de como montar o "esqueleto" de uma página web moderna respeitando a semântica, o que é fundamental para a acessibilidade e para os motores de busca (Google). Contém exemplos explicativos de:
* **`<header>` e `<nav>`:** Para definir o topo da página e os menus de navegação.
* **`<main>`:** Demarcando o conteúdo principal e mais importante do site.
* **`<article>` e `<section>`:** Como isolar o conteúdo de forma lógica e independente (ideal para postagens de blogs e agrupamento de informações).
* **`<aside>`:** Organização de conteúdos secundários, como barras laterais e propagandas.
* **`<footer>`:** Estruturação do rodapé com informações de direitos autorais e links úteis.

## 🚀 Como Visualizar

Por se tratar de um projeto frontend estático, não há necessidade de instalações complexas ou configurações de ambiente.

1. Clone o repositório para a sua máquina:
   ```bash
   git clone [https://github.com/DalgonaFox/htmlStuff.git](https://github.com/DalgonaFox/htmlStuff.git)
   ```
2. Abra a pasta do projeto.
3. Dê um clique duplo nos arquivos .html para abri-los diretamente no seu navegador preferido, ou utilize a extensão Live Server no VSCode para visualizar as edições em tempo real.
